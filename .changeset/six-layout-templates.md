**feat**：逻辑图、组织结构图、树形图、时间轴、矩阵图各扩展为六套主流结构。

- 逻辑图：向右 / 向左 / 向下 / 向上 / 双向平衡 / 大纲缩进
- 组织结构图：向下 / 向上 / 向右 / 向左 / 双向平衡 / 环形放射
- 树形图：向右 / 向左 / 向下 / 向上 / 双向平衡 / 环形放射
- 时间轴：横向上下一侧交替、横向上方单侧、横向下方单侧、纵向左后交替、纵向左侧单侧、纵向右侧单侧
- 矩阵图：2×2 四象限、2×3 六宫格、3×2 六宫格、3×3 中心九宫格、两栏对比、三栏对比

时间轴悬挂分支改为绕行公共干线，避免连线穿过同侧兄弟节点；矩阵对比模板以根节点作为左栏标题。旧布局 id 继续自动迁移到对应新结构。
