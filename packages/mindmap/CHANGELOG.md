# @eflink-tech/mindmap

## 0.2.0

### Minor Changes

- 9101276: **feat**：补齐编辑器工具链——多选批量编辑（样式 / 标记 / 删除 / 概要 / 外框）、查找与替换（高亮命中、逐条导航、按节点替换）、节点内嵌图片与显示宽度、联系线 / 外框 / 概要样式面板（颜色、线宽、文字、删除）、主题微调（主色、6 个分支色、形状、字号、连线，可恢复默认）、分支级生长方向（任意节点可覆盖左 / 右 / 上 / 下，只作用于其子树；固定网格结构自动忽略）。
- 9101276: **feat**：新增 FreeMind（`.mm`）、OPML（`.opml`）、Markdown（`.md` / `.markdown`）与百度脑图 KityMinder（`.km`）导入。FreeMind 保留备注、链接、折叠、左右分侧、内置图标与字体/连线样式；OPML 兼容 `text`/`title`、`_note`、`_link`；Markdown 支持标题与缩进列表混排、任务复选框并跳过代码块；KityMinder 保留优先级/进度、备注、链接、图片、折叠与模板布局。工具栏「导入」入口按扩展名统一分发。
- bde8ab6: **feat**：鱼骨图替换为六套主流结构并补充 6M 因果分析——经典原因型（头右横置）、反向对策型（头左横置）、纵向·头下、纵向·头上、6M 对称型、6M 因果分析（原因 → 结果方向，鱼脊/大骨/二级原因带箭头）、梳状整理型。骨骼长度统一、二级/三级原因沿尾轴延伸，方向键导航按各结构生长轴适配；旧 `fishbone-1/2/3`、`fishbone-right` 文档自动迁移到新结构。
- 85e6032: **feat**：思维导图、括号图、逻辑图、组织结构图、树形图、时间轴、矩阵图扩展为多套主流结构。

  - 思维导图：双向平衡 / 右侧单向 / 左侧单向 / 向下发散 / 向上发散 / 放射环状
  - 括号图：向右 / 向左 / 向下 / 向上 / 双向括号 / 缩进大纲
  - 逻辑图：向右 / 向左 / 向下 / 向上 / 双向平衡 / 大纲缩进
  - 组织结构图：向下 / 向上 / 向右 / 向左 / 双向平衡 / 环形放射 / 圆角组织架构
  - 树形图：向右 / 向左 / 向下 / 向上 / 双向平衡 / 环形放射 / WBS 分解
  - 时间轴：横向上下一侧交替、横向上方单侧、横向下方单侧、纵向左右交替、纵向左侧单侧、纵向右侧单侧
  - 矩阵图：2×2 四象限、2×3 六宫格、3×2 六宫格、3×3 中心九宫格、两栏对比、三栏对比

  新增 WBS 分解（根下分列、列内逐级缩进堆叠）与圆角组织架构（经典正交总线、拐角倒圆）。时间轴悬挂分支改为绕行公共干线，避免连线穿过同侧兄弟节点；矩阵对比模板以根节点作为左栏标题。旧布局 id 继续自动迁移到对应新结构。

- 35f58a2: 1. **feat**：新增 `setMindMapStorageBackend`：宿主可注入自定义存储后端对接远端 API（实现 put/get/remove/list/rename）；未注入时行为与之前完全一致。 2. **fix**：修复 StrictMode 下挂载时 effect 双执行导致重复建档的问题。
- 9101276: **feat**：多画布工作表（同一导图多张画布，标签切换 / 重命名 / 删除，切换前自动保存）、模板库（6 套内置模板，创建即套用主题与布局并本地化文案）、演示模式（F5 逐页演示、自动居中高亮、Esc 退出、可全屏）、文件列表页（按导图分组，文件菜单「全部文件」进入）、跨工具导出（XMind / Markdown / OPML / FreeMind）。
- 63be127: **feat**：支持导入 XMind 文件（`.xmind`）。同时兼容 XMind 2020+（`content.json`）与 XMind 8 及更早（`content.xml + styles.xml`）两种包结构，导入时保留节点层级、笔记、标签、链接、内嵌图片、优先级/任务/旗帜/星级/人像/表情标记、折叠状态、外框、概要、联系线、常见结构与基础节点样式；多画布文档取第一个画布。工具栏「导入」入口现在按扩展名自动分发 XMind 与 EFM JSON。
